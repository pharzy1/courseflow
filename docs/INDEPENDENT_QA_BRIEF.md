# CourseFlow independent regression brief

Test the public release at `https://courseflowplanner.com` without trusting repository claims. Inspect the source at `https://github.com/pharzy1/courseflow` and report reproducible evidence.

## Required matrix

- Desktop 1440×900, tablet 768×1024, mobile 390×844.
- Anonymous and signed-in flows; verify account isolation with two test users when credentials are available.
- Search/filter/pagination, section selection, hard constraints, every ranking preference, conflict rejection, score reconciliation, weekly calendars, share-link restoration, `.ics` export, cloud create/restore/duplicate/rename/delete, watchlists, quiet hours, unsubscribe, roadmap, status page, keyboard navigation, screen-reader names, touch targets, contrast, console/network errors.
- Prove generated options are genuinely different and that every preference can affect a ranking fixture. Confirm the headline score equals the visible contribution total.
- Inspect CI for masking fixtures, skipped tests, hard-coded claims, and tests that pass without exercising the primary flow.

Return P0–P3 findings with steps, viewport, expected/actual behavior, evidence, affected code when identifiable, and a recruiter-readiness score for visual quality, functionality, accessibility, engineering evidence, and résumé readiness. Explicitly distinguish defects from disclosed data limitations.
